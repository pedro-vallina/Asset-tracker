# Asset-tracker
Small project to run on a raspberry pi. It traks the real-time prices of different assets, and provides differents options of visualization.

El programa debe de hacer varios tipos de descargas. Para empezar, debe descargar 
datos de btc, spx, uranio y oro. De cada activo, debe descargar:

- Periodo máximo y intervalo de 1 o 3 meses
- 10 años y intervalo de 1wk
- 1 año y intervalo de 1d
- 1 mes y intervalo de 1h
- 1 semana y intervalo de 30min
- 1 día y intervalo de 15 min
